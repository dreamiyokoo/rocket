# ベッティング戦略シミュレーション結果

## 概要

実際の DB データ（162 ラウンド）を使い、「100コイン@2x + 50コイン@Nx」の複合ベット戦略を検証する。  
ゲームの流れ（前の結果パターン）は意図的に設計されているという前提のもと、以下の3軸で戦略を比較した。

1. **No-Entry フィルタ** — 買い禁止ゾーンでスキップ（損失局面の回避）
2. **流れ判定エントリー** — 直近 18 ラウンドの 2x 到達率を見て「流れが来ているときだけ賭ける」
3. **賭け額スケール** — 流れの強さに応じて賭け額を増減する

## 流れ（直近18ラウンド内 2x 到達率）の分布

直近 WINDOW=18 内の 2x 到達率をもとに、各ラウンドを3段階に分類。

| 流れ状態 | 定義 | ラウンド数 | 実際の 2x 達成率 |
|---------|------|----------|----------------|
| HOT（熱い） | prob_2x >= 60% | 47 ラウンド | 53%（25/47） |
| WARM（普通） | 50% ≦ prob_2x < 60% | 35 ラウンド | 57%（20/35） |
| COLD（冷え） | prob_2x < 50% | 62 ラウンド | 47%（29/62） |

> **ポイント**: COLD 時はエントリーを避けることで、リスク局面を43%（62/144）削減できる。

- No-Entry + COLD フィルタ併用で **最大62ラウンドをスキップ**（144の43%）

## 戦略の読み方・比較ポイント

### ① vs ③：流れフィルタを追加するだけで何が変わるか

| 指標 | ① ベースライン | ③ 流れ>=50% |
|------|-------------|------------|
| エントリー数 | 144 | 82（43%削減） |
| 最終損益 | +2,650 | +2,650 |
| ROI | +12.3% | **+21.5%** |
| 最大DD | -1,550 | **-150** |

→ **損益は同額だが、賭ける回数が減り ROI と安全性が大幅改善。**

### ③ vs ⑤：賭け額スケールを追加するとどうなるか

| 指標 | ③ スケールなし | ⑤ スケールあり |
|------|-------------|--------------|
| 総賭け額 | 12,300 | 15,825 |
| 最終損益 | +2,650 | **+3,463** |
| ROI | 21.5% | **21.9%** |

→ **HOT 時に増額することで損益が +813 コイン向上（+30.7%増）。ROI はほぼ同等。**

### ④ vs ⑤：閾値60%の厳格フィルタ vs 50%スケール

| 指標 | ④ 流れ>=60% | ⑤ 流れ>=50%+スケール |
|------|------------|---------------------|
| エントリー数 | 47 | 82 |
| 最終損益 | +1,625 | +3,463 |
| 最大DD | **0（負けなし）** | -150 |

→ 60%厳格フィルタは「ほぼ負けない」が、取りこぼしが多く損益は半分以下。  
→ 50%+スケールは「負け額が最小（-150）」を保ちながら最大の損益を確保。

## 推奨戦略（⑤）の詳細

```
Bet1: 100コイン × スケール @ 2.0x で利確
Bet2:  50コイン × スケール @ 3.5x で利確

スケール倍率:
  直近18R内の2x到達率 >= 60%（HOT）  → 1.5倍で賭ける
  直近18R内の2x到達率 >= 40%（WARM） → 1.0倍で賭ける
  直近18R内の2x到達率 <  40%（COLD） → 0.5倍で賭ける

エントリー条件:
  - No-Entry フィルタが「エントリー可」（中央値 >= 1.50x）
  - 直近18R内の2x到達率 >= 50%
```

## 考察

1. **固定で掛け続けるのは非効率**  
   全ラウンドに乗るより「流れが来ているときだけ賭ける」方が同じ損益でも ROI が高く、最大 DD が大幅に縮小する。

2. **流れの強さに応じた増減が最も効果的**  
   HOT 時に1.5倍で乗ることで、同じ戦略・同じ勝率でも損益が約 30% 増加する。

3. **271.45x ライン（指定利確値）について**  
   到達率 1.4%（144R中2回）のため Bet2 目標として設定すると大幅な赤字になる。  
   「来たときに乗る」用の第3ベット（極小額）として別立てで運用するか、到達時の判断の目安として使うことを推奨。

4. **データ数が少ない点に注意**  
   162 ラウンドは統計的にはサンプルが少なく、スパイク2回（86x, 501x）が結果に大きく影響している。  
   データが増えるほど期待値の信頼性が上がる。

## 考察・今後の検討事項

1. **データ数が少ない**（162ラウンド）ため、スパイク2回（86x, 501x）が結果に大きく影響している。データが増えるほど信頼性が上がる。

2. **No-Entry フィルタの条件拡張**  
   現在は `low_expected_value` のみ発動。以下のパラメータ調整でスキップ率を高めると安全性が向上する可能性がある。
   - `NO_ENTRY_LOW_EV_MEDIAN_THRESHOLD`: 1.50 → 1.80 に引き上げ
   - `NO_ENTRY_LOW_MULTIPLIER_THRESHOLD`: 1.30 → 1.50 に引き上げ（連続低倍率条件を発動しやすく）

3. **271.45x ライン（指定利確値）について**  
   この倍率を Bet2 に使うことは、現データ（到達率 1.4%）では非現実的。  
   「到達したときの大口利確」として Bet2 とは別に少額の第3ベットとして運用することを検討。
