# [フロントエンド] 入力画面実装（認証済み専用）

## 概要

入力者がラウンド倍率を一括入力し、送信・リセット操作を行う画面を実装する。
未ログインでアクセスした場合は `/login` にリダイレクトする。

## 画面仕様

- ルート: `/input`
- アクセス制限: 認証済みユーザーのみ

### 要素

1. **倍率入力エリア**
   - `<textarea>` で1行1値の改行区切り入力
   - プレースホルダー例:
     ```
     1.01
     1.5
     20
     2.05
     100
     ```
   - 送信ボタン押下で改行をパースして `POST /api/v1/rounds` へ送信

2. **送信ボタン**
   - 送信中はローディング表示
   - 成功時: テキストエリアをクリアしてトースト通知を表示

3. **リセットボタン**
   - クリック時に確認ダイアログを表示（「全データを削除します。よろしいですか？」）
   - 確認後に `DELETE /api/v1/rounds` を実行

4. **ステータス表示**
   - 現在の蓄積件数
   - 分析開始まで残り何件か（18件に達していれば「分析中」と表示）

5. **ログアウトボタン**
   - クリックで JWT を破棄し `/login` に遷移

## バリデーション（クライアント側）

- 空白行は無視する
- 数値以外の行が含まれる場合は送信前にエラー表示する
- 0 以下の値が含まれる場合は送信前にエラー表示する

## 受け入れ条件

- [ ] 未ログインでアクセスすると `/login` にリダイレクトされる
- [ ] 改行区切りで複数の倍率を入力して送信できる
- [ ] 送信成功後にテキストエリアがクリアされる
- [ ] 数値でない行はクライアント側でエラーを表示し送信されない
- [ ] リセットボタンは確認ダイアログを経由して実行される
- [ ] リセット成功後にステータス表示が「0件」に更新される
- [ ] ログアウトボタンで正常にログアウトできる

## 技術メモ

- 改行パース: `textarea.value.split('\n').map(s => s.trim()).filter(Boolean)`
- `POST /api/v1/rounds` の `values` フィールドに数値配列として渡す
- ステータス表示は `GET /api/v1/analysis` の `total_rounds` / `ready` を使う
