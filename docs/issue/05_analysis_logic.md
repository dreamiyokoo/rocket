# [ロジック] 確率遷移・移動平均の計算実装

## 概要

蓄積されたラウンド倍率データから確率遷移と各種統計値を計算するロジックを実装する。
最低 18 件のデータが存在しない場合は算出しない。

## 計算仕様

### 確率遷移（移動平均）

ウィンドウサイズ = 18 件 を基準とする。

```
prob_2x  = (直近18件中、multiplier >= 2.0 の件数) / 18
prob_5x  = (直近18件中、multiplier >= 5.0 の件数) / 18
prob_10x = (直近18件中、multiplier >= 10.0 の件数) / 18
```

`history` として、過去の各時点の確率値も返す（最大 72 件分）。

- `total_rounds < 18` の間は `history` は空で、分析自体を返さない
- `total_rounds = 18` になった時点で、最初の 18 件ウィンドウに対応する 1 件目の履歴を生成する
- 19 件目以降はウィンドウを 1 件ずつ右にスライドし、ラウンド追加ごとに `history` へ 1 件追加する
- `history` の件数は `max(0, min(total_rounds - 17, 72))`
- 72 件を超える場合は直近 72 ウィンドウ分のみ保持する
- `chart_data` は生の倍率時系列で、件数は `min(total_rounds, 72)` とする

### その他の統計値

| 指標 | 対象 | 計算式 |
| --- | --- | --- |
| `moving_avg` | 直近 18 件 | 算術平均 |
| `median` | 直近 18 件 | 中央値 |
| `std_dev` | 直近 18 件 | 標準偏差（不偏） |
| `max` | 全蓄積データ | 最大値 |
| `min` | 全蓄積データ | 最小値 |

## 受け入れ条件

- [ ] データが 18 件未満のとき `ready: false` を返し、統計値は `null`
- [ ] `prob_2x / prob_5x / prob_10x` が正しく算出される
- [ ] `history` が最大 72 件分の確率値配列として返される
- [ ] `moving_avg`・`median`・`std_dev` が直近 18 件で計算される
- [ ] `max`・`min` が全蓄積データを対象に算出される
- [ ] 単体テストが存在する（正常系・18件未満・全件 1.0 未満など）

## 技術メモ

- Python の `statistics` モジュールまたは `numpy` を使用する
- 計算ロジックは `app/analysis/calculator.py` に分離してテスタブルにする
- `history` の計算はウィンドウをスライドさせながら各時点の確率を再計算する
