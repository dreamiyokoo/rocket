# [フロントエンド] 閲覧画面実装（パブリック）

## 概要

認証不要で誰でも閲覧できる分析結果ダッシュボードを実装する。
リアルタイム性を重視し、一定間隔でポーリングまたは WebSocket で更新する。

## 画面仕様

- ルート: `/`（トップページ）
- アクセス制限: なし（パブリック）

### 要素

1. **ステータスバー**
   - 蓄積件数（例: `23 rounds`）
   - 分析状態（`ready` が `false` なら「あと X 件で分析開始」と表示）

2. **確率パネル**（`ready: true` のときのみ表示）

   | 指標 | 表示例 |
   | --- | --- |
   | 2x 以上確率 | `44.4%` |
   | 5x 以上確率 | `16.7%` |
   | 10x 以上確率 | `5.6%` |

3. **全体グラフ**
   - 横軸: ラウンドインデックス（最大 72 件）
   - 縦軸（左）: 倍率（対数スケール推奨）
   - 縦軸（右）: 確率 0〜100%
   - 描画ライン:
     - 倍率折れ線（青）
     - 2x 以上確率ライン（緑）
     - 5x 以上確率ライン（黄）
     - 10x 以上確率ライン（赤）

## 受け入れ条件

- [ ] 認証なしで `/` にアクセスできる
- [ ] `ready: false` のとき確率パネルとグラフが非表示（またはグレーアウト）になる
- [ ] グラフに倍率と3本の確率遷移ラインが描画される
- [ ] グラフは最大 72 件のデータを表示する
- [ ] 30 秒ごとに自動更新される（ポーリング）
- [ ] モバイル表示でもグラフが崩れない

## 技術メモ

- グラフライブラリ: `Chart.js` + `react-chartjs-2` または `Recharts`
- データ取得: `GET /api/v1/analysis`
- ポーリング間隔: 30 秒（SWR の `refreshInterval` を使用）
- 倍率の縦軸は対数スケール（`1.0` 〜 `100+` の幅が大きいため）
