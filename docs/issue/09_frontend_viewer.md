# [フロントエンド] 閲覧画面実装（パブリック）

## 概要

認証不要で誰でも閲覧できる分析結果ダッシュボードを実装する。
リアルタイム性を重視し、一定間隔でポーリングまたは WebSocket で更新する。

## 画面仕様

- ルート: `/`（トップページ）
- アクセス制限: なし（パブリック）

### 要素

1. **ステータスバー**
   - 蓄積件数（例: `23 rounds`）
   - 分析状態（`ready` が `false` なら「あと X 件で分析開始」と表示）

2. **確率遷移グラフ**（`ready: true` のときのみ表示）

   - 横軸: ウィンドウインデックス（history の件数分、最大 72 点）
   - 縦軸: 確率 0〜100%
   - 描画ライン:
     - 2x 以上確率遷移（緑）← `prob_2x.history`
     - 5x 以上確率遷移（黄）← `prob_5x.history`
     - 10x 以上確率遷移（赤）← `prob_10x.history`
   - 各ラインの末端（最新値）をラベル表示: `44.4%` など

3. **倍率グラフ**
   - 横軸: ラウンドインデックス（最大 72 件、`chart_data` を使用）
   - 縦軸: 倍率（対数スケール推奨）
   - 描画ライン: 倍率折れ線（青）

## 受け入れ条件

- [x] 認証なしで `/` にアクセスできる
- [x] `ready: false` のとき確率遷移グラフが非表示（またはグレーアウト）になる
- [x] 確率遷移グラフに2x・5x・10x の3本のラインが描画される
- [x] 倍率グラフは最大 72 件のデータを表示する
- [x] 30 秒ごとに自動更新される（ポーリング）
- [x] モバイル表示でもグラフが崩れない

## 技術メモ

- グラフライブラリ: `Chart.js` + `react-chartjs-2` または `Recharts`
- データ取得: `GET /api/v1/analysis`
- ポーリング間隔: 30 秒（SWR の `refreshInterval` を使用）
- 確率遷移グラフのデータ: `prob_2x.history` / `prob_5x.history` / `prob_10x.history`（18件ウィンドウごとの確率値）
- 倍率グラフのデータ: `chart_data`（各ラウンドの倍率）、縦軸は対数スケール（`1.0` 〜 `100+` の幅が大きいため）
