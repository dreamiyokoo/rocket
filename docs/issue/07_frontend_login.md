# [フロントエンド] ログイン画面実装

## 概要

入力者が ID / PW でログインする画面を実装する。
ログイン成功後は入力画面（`/input`）にリダイレクトする。
ログイン済みでこのページを開いた場合は `/input` にリダイレクトする。

## 画面仕様

- ルート: `/login`
- 要素:
  - ユーザー名フィールド
  - パスワードフィールド
  - ログインボタン
  - エラーメッセージ表示エリア（認証失敗時）

## 受け入れ条件

- [ ] 正しい ID / PW を入力してログインすると `/input` に遷移する
- [ ] 誤った認証情報では画面内にエラーメッセージが表示される（ページ遷移しない）
- [ ] ログイン中に `/login` を開くと `/input` にリダイレクトされる
- [ ] パスワードフィールドは `type="password"` でマスクされる
- [ ] ログインボタン押下中はローディング状態を表示する

## 技術メモ

- JWT は `httpOnly Cookie` または `localStorage` に保存する（要検討）
- API: `POST /api/v1/auth/login`
- Next.js の `middleware.ts` でルート保護を実装する
